# GITAMW Python Smart IDE — Student & Faculty User Manual

**Gouthami Institute of Technology for Women (Autonomous), Proddatur**

---

## 1. Student Login

1. Double click the **GITAMW Python Smart IDE** icon.
2. Watch the 3-second animated Splash Screen.
3. Enter your student credentials:
   - **Student Name** (e.g. K. Sravani)
   - **Roll Number** (e.g. 212M1A0501)
   - **Branch** (CSE / CSE-AI / CSE-DS / ECE)
   - **Year & Semester** (e.g. III Year / Semester 1)
   - **Section** (Sec A, B, C)
4. Check the Academic Integrity Agreement box and click **Login**.

---

## 2. Editor & Code Execution

- **Write Code**: Enter Python code in the central Monaco Editor window.
- **Run Code**: Press **F5** or **Ctrl + Enter** or click the green **Run (F5)** button in the top action bar.
- **Console Output**: View printed outputs in the bottom Output Console.
- **Plots & Charts**: Matplotlib graphs generated using `plt.show()` render directly in the **Plots & Visuals** tab.
- **Save Program**: Press **Ctrl + S** or click **Save**. Saved files appear under the **Saved Programs** sidebar tab.

---

## 3. Smart Error Explainer

When your program encounters an error (e.g., missing colon, undefined variable, division by zero):
1. The IDE automatically opens the **Smart Error Explainer** tab.
2. It displays:
   - The exact line number and line of code containing the error.
   - Plain English explanation of why the error occurred.
   - Beginner-friendly suggestion on how to fix it.

---

## 4. Installing Packages

1. Click the **Packages** tab on the left sidebar.
2. View preinstalled data science packages (NumPy, Pandas, Matplotlib, Scikit-learn, etc.).
3. To install a new package, type `!pip install <package_name>` inside the code editor or use the package installer search bar.

---

## 5. Exporting Execution Reports

Click **Export Report** in the top action bar to download a styled HTML report containing your student details, program source code, output, runtime telemetry, and error log for lab submission.
